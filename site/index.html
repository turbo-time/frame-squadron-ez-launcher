SSquadrons VR launcher
Steam Machine + Steam Frame

Squadrons in VR.
One click to launch.

Install two controller choices on the Steam Machine. Then stream from its Steam library to your Frame over Steam Remote Play.

curl -fL https://raw.githubusercontent.com/turbo-time/frame-squadron-ez-launcher/main/install.sh -o /tmp/squadrons-install.sh && bash /tmp/squadrons-install.sh

Run this on the Steam Machine. In Desktop Mode, open Konsole, paste the command, and press Enter. Review the installer source first if you prefer.

From install to flight

1

Install on the Machine

The installer adds both launcher choices to your Steam library. No password, SSH setup, or Frame-side install.

2

Choose your controller

Pick Frame Controllers or Steam Controller before you start streaming.

3

Stream from the Frame

Open the Machine's library on the Frame and select Stream on that launcher.

Made for a clean handoff

Returns the TV to Steam

If the Frame disconnects for 15 seconds, Squadrons gets a normal quit request. SteamVR closes when safe, returning the Machine to Steam Home.

Open and inspectable

The installer and launcher scripts are in the public GitHub repository. Everything installs in your user account; the installer does not need root access.

Requires a SteamOS x86_64 host with Squadrons and SteamVR installed, and a Steam Frame paired for Remote Play. The installer detects the Frame and explains that no Frame-side install is needed.
